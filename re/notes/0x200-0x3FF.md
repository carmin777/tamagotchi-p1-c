# ROM 0x200–0x3FF — reset, clock screen, menu input, care-event dispatch

Source: `tools/asm.py 0x200 0x3FF` + the routines it calls (0x000–0x0FF, 0x5xx, 0x7xx, 0x8xx, 0xAxx, 0xCxx, 0xDxx, 0xFxx)
+ `harness/trace` runs (scripts in `out/r200/s*.txt`). `(?)` = hypothesis.

## 0. Conventions needed to read the code

- agg23's `label_N` labels are not page addresses: `pset P; call X` calls `P:X`
  (e.g. `pset 0x5; call 0x4A6` = 0x5A6). 0x4xx/0x5xx words in the listing are the *encoding* of call/calz.
- `lbpx mx,0xHL`: writes the **low nibble (L) to M(X)** and the **high (H) to M(X+1)**, X += 2. `retd 0xHL` likewise (M(X)=L, M(X+1)=H). So `lbpx mx,0x3D` => M(x)=0xD, M(x+1)=3.
- `jpba`: PC = (NP<<8) | (B<<4) | A. `ld y,0xHL`: YH=H, YL=L. XP/YP = page (high nibble) of the RAM address.
- Flags in the F register (used by `push f; pop b`): C=bit0, Z=bit1, D=bit2 (decimal), I=bit3.
- **Buttons** (tamalib `hw.c`): K00=R(C), K01=M(B), K02=L(A). In RAM the bits are active-high: bit0=R, bit1=M, bit2=L.
  - M(0x026) = buttons *held* now; M(0x027) = *falling edges* accumulated (OR) since the last read
    (it also receives repeats when the same state persists for 8 ticks). Written by `prog_timer_int` (0x16F).
  - `copy_0x026_7_to_8_9` (0x021): A=M(0x026), B=M(0x027), clears 0x027, copies to M(0x028)=A, M(0x029)=B. **Returns A=held, B=edges.**
    All the code below uses "A/B after that call" and/or tests M(0x028)/M(0x029).
- Nibble pairs: an 8-bit value = M(n) low, M(n+1) high (nibble little-endian).
- Wait timer: `copy_xhl_to_0x022_or_loop_0x023` (0x03C) puts XH:XL in M(0x022/023) and **blocks** until `prog_timer_int` (256 Hz/divisor) decrements it to 0. `wait(n)` below.

## 2. Routines

### 2.1 0x200–0x205 `poll_cancel_or_reset` (agg23 `label_70`)
Copies buffer→LCD, reads buttons. `if (held==5) goto soft_reset` (L+R held). Return: **Z=0 if M(0x029)&1 (R pressed)**, otherwise Z=1.
Callers: 0x3B0, 0x3C9 (death screen). Calls: copy_video_buf_to_vram, copy_0x026_7_to_8_9.
```c
bool poll_cancel_or_reset(void){ copy_video_buf_to_vram(); read_buttons(&A,&B);
  if (A==5) soft_reset(); return (B&1)!=0; }
```

### 2.2 0x206–0x226 `soft_reset_keep_clock` (`label_71`; L+R on the death screen)
Restarts the game preserving the time: saves 0x010..0x015 into 0x272..0x277, SP=0xFF, flags=0, `set_init_mem_and_int` (clears RAM and reinitializes I/O), restores the clock, `set_f_0x07D`, music 0x80 (if 0x07B), `game_init` (label_232 @0x761: initial values — 0x5D=0, 0x5E=1, 0x40=0x41=1, 0x46=5, 0x48..0x4F, 0x5C=0, 0x200..0x20F…, 0x0F=F, 0x12=F, 0x15=5, 0x16=0x28…), `render_pet` (label_142 @0x465), M(0x03C)=F, waits for all buttons to be released (`while(held&7)`), `goto pet_main_loop` (0x517).
Does not return. Called only by 0x203.

### 2.3 0x227–0x229 `springboard_copy_6_mx_my` / `copy_6_mx_my_bank0_ret` — trampoline to page 0x12 (`copy_6_mx_my`, 6 nibbles MX→MY). 0x242–0x243 `springboard_set_init_mem_and_int` likewise to 0x1E0.

### 2.4 0x22A–0x241 `reset_vect_cont` (cold start; vector 0x100→0x114→here)
```c
if (svd_voltage_ok()) io[0xF70]=1;       // osc 32kHz / >3.1V (check_svd_voltage_set_xp_f 0x1E3)
M[0x270] = io[0xF40] & 7;                // raw K0 (active-low)
set_init_mem_and_int();                  // clears RAM except 0x270 (clears 0x000-0x0DF, 0x100-0x26F and the whole LCD; loop 0x047 clears 16 nibbles per iteration — the previous list was wrong), I/O, 0x7B=F, 0x7C=5
set_f_0x07D(); play_tune_if_sound(0x80); // 0x23A
if (M[0x270]==3) goto factory_lcd_test;  // 3 = only K02 (L) pressed  (confirmed: `hold L` in the trace enters 0x256)
goto clock_set_start;                    // 0x97F: init game (0x761), render pet, loop until M → set_time_mode (0x553)
```
`set_init_mem_and_int_cont_mem_clear` 0x244–0x255 is the continuation (page 2) that clears RAM with `clear_8_starting_at_a_xp` and jumps to `..._cont_set_mem` (0x1200).

### 2.5 0x256–0x292 `factory_lcd_test` (`label_80/81/85/83/84`) — factory LCD test (L pressed at reset)
Four patterns; each waits for **exactly** one button to be held (A==M(0x000)), plays a beep (0x94) and goes on.
| step | icon mask 0x2C/2D | buffer pattern 0x100–0x1FF (repeated nibbles A,A,B,B) | waits for |
|---|---|---|---|
| 1 | 0xFF | F,F,F,F (all pixels) | M (2) |
| 2 | 0x5A (2C=A,2D=5) | A,A,5,5 | R (1) |
| 3 | 0xA5 | 5,5,A,A | L (4) |
| 4 | 0x00 | 0x100–0x17F = (1,0)…; 0x180–0x1FF = (0,8)…; corners 0x100,0x13E,0x180,0x1BE = FF (frame) | M (2) |
Then `goto 0x97F` (normal start). Pseudo: `label_81(mask, pat, btn){ M[0]=btn; fill(0x100,256,A=hi(pat),A,B=lo(pat),B); update_icons(); copy_video_buf_to_vram(); do read_buttons(); while(A!=M[0]); tune(0x94); }`.

### 2.6 0x293–0x2C2 `clock_screen_loop` (agg23 `label_88/89/92/93`) — CLOCK screen
Entry points: 0x2C2 (after an event), 0x4FD, 0x590 (exit from time setting). Loop:
```c
label_88: set_icon_mask(0) /*label_238*/; clear_page_0x100(); read_buttons();
label_89: cursor=(4,0xC); M[0x2A]=0,M[0x2B]=4;
  render_clock();                    // label_181 @0x5A6: clears 0x2E; hh:mm (+AM/PM glyph A/B via m9 bit3 -> misc_render) in the buffer
  /* 5-cell seconds bar: */ m5=5; a=M[4]; if(a>=6) a+=3; M[4]=a;
  for(i=0;i<5;i++){ M[4]--; glyph = 0xA | ((M[4]&8)?1:0); render_clock_with_b_0(glyph); }   // 0x2A4–0x2AC (?) m4 = seconds nibble coming from label_181
  copy_video_buf_to_vram();
  if (check_events()) { dispatch_event(); goto label_88; }     // 0xF00 -> NZ => 0x2C1
label_92:
  wait(2); read_buttons();           // store_0x02_into_0x022_3
  if (B&2) goto 0x508 /*M: go to the pet screen*/;
  if (A==5) goto 0x553 /*L+R: set the time (set_time_mode)*/;
  if (M[0x7C]==0) goto 0x508 /*egg ready to hatch*/;
  if (M[0x2E]==0) goto label_92;     // wait 1 s
  goto label_89;                     // redraw
```
Note: while waiting, this screen also processes `check_events`.

### 2.7 0x2C3–0x2F2 `menu_poll_input` (`label_94`…`label_100`)  — **icon menu input**
Callers: 0x530 (main pet loop), 0xE65. Input: none. Output: A = M(0x075) (cursor); flags:
| situation | C | Z | note |
|---|---|---|---|
| no event | 0 | 0 | |
| **L** (M(0x029)&4) | 0 | 0 | beep(0x94); `if (++M[0x75] >= M[0x76]) M[0x75]=0` |
| **M** (&2) | 0 | 1 | beep(0x94) — "confirm" |
| **R** (&1) | 1 | 1 | beep — "cancel" |
| timeout (M[0x57]==0 && M[0x77]!=0) | 1 | 0 | |
Any button (`(A|B)&7`) reloads `M[0x57]=M[0x77]` if 0x77≠0. The caller does `push f; pop b` and tests B&1 (cancel/timeout → 0x517) and B&2 (confirm → dispatches by cursor via the 0x7xx table).
```c
uint8_t menu_poll_input(flags *f){ read_buttons(); if((A|B)&7 && M[0x77]) M[0x57]=M[0x77];
 if(M[0x29]&4){beep(); if(++M[0x75]>=M[0x76]) M[0x75]=0; C=0;Z=0;}
 else if(M[0x29]&2){beep(); C=0;Z=1;}
 else if(M[0x29]&1){beep(); C=1;Z=1;}
 else if(M[0x57]!=0 || M[0x77]==0){C=0;Z=0;} else {C=1;Z=0;}
 return M[0x75]; }
```
0x2F3–0x2FF: 13×`nop7` (padding).

### 2.8 0x300–0x306 table + 0x307–0x30B `dispatch_event` (`jump_table_0x300`)
```c
void dispatch_event(void){ ev = M[0x5C]; M[0x5C]=0; switch(ev){0:return;1:ev_bedtime();2:ev_call_a();3:ev_call_b();4:ev_poop();5:ev_evolve();6:ev_death();} }
```
(`jpba` with B=0: PC=0x300+A; 0x300=`ret`.) Callers: 0x2C1 (clock screen) and 0x54B (pet loop). The one that writes 0x05C is `check_events` (0xF00–0xFD8, outside the range; returns NZ if there is an event) — summary in §6.

### 2.9 Event 1 — 0x30C–0x31B `ev_bedtime` (`label_102`) — bedtime
`M[0x4A]=0xF` (sleeping); `M[0x204..205] = (M[0x5D]==1) ? 0x3D : 0x00`; `jmp set_buzzer_0xA5` (0x318): `play_tune(ptr=0xA5, repeat=A=8)` = `xp_0_if_0x7B_set_clear_0x32_store_yhl` (if 0x07B≠0: M32=0, M36/37=Y, M58=A, M59=B=0).

### 2.10 Events 2 and 3 — 0x31C–0x328 (`label_106/107/108`) — attention calls
- Event 2 (0x31C): `M[0x208] = (M[0x5D]==1) ? 0xD : 1;` then `play_tune(0xA5,8)`.
- Event 3 (0x324): `M[0x209] = 1;` then the same.
Side effect: 0x208/0x209≠0 ⇒ "attention" icon (0x2D|=8 in label_240/0x7D1). They rise by 1 per minute (0xCDB `label_328`, saturating at F) up to F ⇒ `check_events` counts a care mistake.
Trace: 1st event 2 at t=310 s (right after hatching): 0x208 0→0xD, 365s E, 425s F (+0x42++), …

### 2.13 Event 6 — 0x374–0x3CF `ev_death` (`label_116`…`121`)
Trigger (check_events 0xF74): `M[0x49]>=3` (3 illnesses) **or** starvation (non-baby: 0x20A..C ≥ 0x2D0) **or** sick for ≥ 0x160 min (0x20D..F) **or** `M[0x4F]>=5`.
```c
set_icon_mask(0); copy_video_buf_8x();
M[0x74]=0;                        // non-skippable animation
M[0x48]=M[0x49]=0; M[0x4A]=0; M[0x4B]=0xF; M[0x4C]=M[0x4D]=0;
m6 = M[0x5D];                     // form that died
tune(0xBF); play_anim(5, A=0xA,B=0xA)x4;   // label_123 = anim_id 5, pose 0xA, 10 s
tune(0xC4); play_anim(...)x1; tune(0xC9); play_anim(...)x1;
M[0x5D]=0;
if (M[0x4E]!=0) {                 // died of old age: the angel rises
   draw_dying(); wait(27); M[0x22..23]=72;           // 0x1B=27 ticks, 0x48=72 ticks
   do { draw_dying(); clear_page_0x100(); draw_angel_and_flush(); } while (M[0x22]|M[0x23]);
   wait(27); }
tune(0xCE); read_buttons();
do {                              // tombstone screen
   clear_page_0x100(); M[0x80]+=8; flip=M[0x80];            // toggles 0/8 => mirrors
   cursor=(0,0); draw_sprite(pose=3, flags=flip);           // label_128: upper + lower half of character 0x5D(=0)
   cursor=(0,2); draw_sprite(pose=4, flags=0);
   if (poll_cancel_or_reset()) {  // R
      tune(0x94); misc_render(9,1)@0x1D0;                 // glyph
      misc_render(M[0x54],1)@0x150; if(M[0x55]) misc_render(M[0x55],0)@0x140;   // age
      scroll_in(a=2,b=2);        // label_305 @0xAF0
      do ; while(!poll_cancel_or_reset()); tune(0x94); scroll_out(b=0xE); // label_156 @0x500
   }

```
Leaving the tombstone: holding L+R (poll_cancel_or_reset → `soft_reset_keep_clock`) = new egg, clock preserved. (The R flow repeats the tombstone.)

## 3. Page-0 helpers used (for the rewrite; 0x000–0x0FF)
`render_asset` 0x000 (gfx 0x1000+ via M0/M1/M2), `set_f_0x07D` 0x009 / `clear_0x07D` 0x012 (turn interrupts on/off around critical sections, preserve A,X), `copy_0x026_7_to_8_9` 0x021, `copy_xhl_to_0x022` 0x02C, `or_0x022_and_0x023` 0x035, `clear_page_0x100` 0x040 (clears 0x100–0x1FF and M(0x2A)=0), `copy_video_buf_to_vram` 0x056 (Y={1,M2B,M2A} → LCD 0xE00/0xE80…), `check_0x04A_highbit` 0x0B3, `if_0x7B_set_clear_0x32_store_yhl*` 0x0B7–0x0CC (= `play_tune`), `zero_a_xp` 0x0EF, `zero_b_xp` 0x0F2, `one_a_xp` 0x0F5, `check_0xX5D_is_1` 0x0F8, `bit_high_at_0x048` 0x0FD (leaves X=0x48; Z=1 if not sick).

## 4. Music: `play_tune(ptr, repeat)`
`xp_0_if_0x7B_set_clear_0x32_store_yhl(A=repeat)`: if M(0x07B)≠0: M(0x32)=0, M(0x36)=YL, M(0x37)=YH, M(0x58)=A, M(0x59)=B. The sequence is read in `configure_buzzer` (0x1A0) on every tick from the table at 0xE7D+ptr. Pointers used here: 0x80 start-up, 0x94 button beep, 0x97 sound on/off (0x7B^=F, in the pet loop 0x54D), 0xA5 bedtime/call, 0xAE evolution, 0xBF/0xC4/0xC9 death, 0xCE tombstone.

## 5. Flow (how this range fits together)
```

                └─────────────────────────────────────────────────────────────────> 0x97F
```

Note: in the pet loop (0x533–0x539) `held==5` + edge ⇒ toggles sound (`M[0x7B]^=F`, tune 0x97).

## 6. `check_events` (0xF00–0xFD8; outside the range, only what is needed)
Produces M(0x5C) and returns Z=0 if ≠0. Only runs if M(0x7C)==F and M(0x5C)==0. Summary (medium confidence):
- sleeps/wakes by time (0x14/0x15 vs 0x31..0x34; the baby uses different thresholds): on waking it does M[0x4A]=0, M[0x4B]=F, age 0x54/55++ (cap 99); bedtime ⇒ **event 1**.
- 0x200/201 reached 0 (min): reloads from 0x234/235; `M[0x40]` -= 4; if <4 ⇒ `M[0x40]=0`, **event 2** (likewise 0x202/203, 0x41, 0x236/237).
- 0x213/214 accumulator (non-baby) overflowed without carry ⇒ **event 3** (?).
- 0x206/207==0 ⇒ **event 4**.
- 0x210..212==0: if M[0x50]<F ⇒ **event 5**; otherwise M[0x4E]=F and `M[0x4F]++` (lifespan mistake).
- 0x20D..20F==0 and healthy ⇒ M[0x48]=F, M[0x49]++ (sick).
- death ⇒ **event 6** (conditions in §2.13). Penalties: `label_388`: M[0x42]++ (sat. F) and `M[0x4F]++` when M[0x50]==F and 0x210..212==0; `label_389`: saturated ++.
- 0x208/0x209==F ⇒ clears and mistake (0x42++ / 0x51++).
Per-minute tick that feeds everything: `label_319` @0xCA1 (decrements 0x200,0x202,0x206 (8 bits); increments 0x208,0x209 saturating; counts 0x20A.. if a heart is 0; 0x20D.. ±1; 0x210.. −1).

## 8. Data: evolution tables (`label_339`…`345`, 0xD9C–0xDC5; loaded into RAM[0x90..] by `label_346`)
Entry = 4 nibbles `[min_0x42, min_0x51, new_0x50, new_0x5D]`; the **first** entry with `M[0x42]>=min0 && M[0x51]>=min1` wins.
