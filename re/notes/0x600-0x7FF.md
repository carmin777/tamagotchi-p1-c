# ROM 0x600–0x7FF

Conventions: `M(a)` = RAM nibble at address `a` (XP:XH:XL); `A,B` = registers; `C,Z,D` = flags.
"page 0" = `calz` (0x000–0x0FF). `label_N` labels are agg23's. `(?)` = hypothesis.
Verified with the emulator (`harness/trace`, ROM with the `jp nc,label_294` at 0x58C replaced by nop7 only so as to
get past the clock-setting screen and reach the main loop; nothing inside 0x600–0x7FF was changed).

## Overview
This range contains, almost entirely, **handlers for the main menu actions** (medicine, guessing game,
food), the **"new game" initialization** (`label_232`), the **8x8 tile renderer** (`misc_render`)
and the **routine that lights the LCD icons** (`label_238/242`).

### Main menu dispatch (how we get here)
`label_164` (0x543, outside the range) stores `M(0x0A0)=n` and does `pset 7; jpba` with `B:A = 2*n` → table at 0x700.
`n = 0` (no icon selected) and `n = 1..7` = icon `n-1` lit on the LCD (`n=8` goes back to 0).

| n | LCD icon | target (0x700+2n) | routine |
|---|---|---|---|
| 0 | none (shows clock/age? screen `label_155`, pg 4) | 0x700 `pset 4; jp label_155` | outside the range |
| 1 | 0 food | 0x702 `pset 7; jp label_220` | `food_menu` 0x710 |
| 2 | 1 light | 0x704 `pset A; jp label_297` | outside (0xAxx): light on/off (`M(0x4B)`=F/0) |
| 3 | 2 game | 0x706 `pset 6; jp label_196` | `play_guess_game` 0x624 |
| 4 | 3 medicine | 0x708 `pset 6; jp label_191` | `medicine_action` 0x600 |
| 5 | 4 toilet | 0x70A `pset D; jp label_336` | outside |
| 6 | 5 status/meter | 0x70C `pset 8; jp label_247` | outside |
| 7 | 6 discipline | 0x70E `pset A; jp label_301` | outside (0xADA): clears `M(0x209)`, `M(0x43)+=4` |

(icon 7 = "attention", not selectable, it is only lit by `label_238`.)  Evidence: `cov.bin` after `L×k, M`: k=1→0x702/0x710,
k=3→0x624.., k=4→0x600.., k=7→0x70E; k=8→0x700.

All the handlers end with `pset 5; jp label_160` (0x51A, back to the menu keeping the icon) or
`jp label_159` (0x517, clears `M(0x0A0)` = deselects and goes back to idle).

### Buttons (`M(0x029)` after `copy_0x026_7_to_8_9`)
bit0 (value 1) = **R** (cancel), bit1 (2) = **M** (confirm), bit2 (4) = **L** (select/advance).
Evidence: the game writes `M(0x081)=4` when L is pressed; `label_94`: `fan mx,4`→advances the cursor.

## 0x600–0x61D `medicine_action` (label_191 / label_192 / label_193)
Handler of the medicine icon (n=4). Entered from the menu; exits to `label_160`.
```c
if (M(0x04A) & 8) goto back_to_menu;          // 0x600: pet sleeping -> nothing      (0x04A bit3 = sleeping, see RAM)
if (!(M(0x048) & 8)) goto refuse_anim;         // 0x602: not sick -> refuses (label_194)
// label_192 (0x606): sick
M(0x048) &= 7;
anim_play(A=8, B=5, Y=3);                      // call label_273 (0x8A9)  "medicine"/grimace animation
M(0x048) = ((M(0x048) | 8) + M(0x23B)) & 0xF;  // 0x610-0x612   (M(0x23B) = "medicine strength" per stage, baby = 0xC)
if (M(0x048) & 8) goto back_to_menu;           // still sick (needs more doses)
// cured (bit3 clear):
copy3(0x20D <- 0x238);                          // reloads the 3-nibble counter 0x20D-0x20F (with 0x07D off)
back_to_menu: pset 5; jp label_160
```
`0x048`: bit3=sick, bits0-2 accumulate doses (?). Effect: two doses cure when 0x048 was set to 0xF (seen: 0x048 becomes F at
~2573 s). Observed in a test: healthy pet -> only 0x600-0x605,0x61E-0x623 run (refusal).
Subroutines:
* `0x61E–0x621` `refuse_anim` (label_194): `A=6,B=5; call label_272 (0x8A8, Y=0)` = "shakes its head" animation; continues to `0x622 label_195` (`pset 5; jp label_160`).
* `0x61C–0x61D` (label_193): `back_to_menu`.
Callers: only the 0x700 table (0x708) and internal `jp`s from 0x624-0x62C (label_194/195).

## 0x624–0x6C7 `play_guess_game` (label_196 / label_197 … label_207)
Game "which way will the little pet turn?" (game icon, n=3). 5 rounds; L = left, M = right; R = quit. 3+ wins ⇒ +1 happiness heart.
Each round's result is **drawn at random** (it does not depend on the guess!): the guess only decides *which side* the pet is drawn turning to.
```c
// 0x624 label_196
if (M(0x04A)&8) goto back_to_menu;                   // sleeping
label_197:                                           // 0x626 (also re-entry for "play again")
if (M(0x048)&8) goto refuse_anim;                    // sick
if (M(0x209) != 0) goto refuse_anim;                 // flag "naughty/needs discipline" (?) see RAM
M(0x05E)=5; anim_select();                           // label_142 (pg4): selects animation 5 (pet waiting)
clear_page_0x100(); anim_step(); copy_buf_and_render_misc();   // label_145 (pg4) / 0x400
tilelist[0x90..0x97] = {FF,1C,FF,1C,1D,FF,1D,FF};    // 0x637-0x63F: full/empty hearts (tiles 0x1C/0x1D)
sound(0xD6);                                         // if M(0x07B) (sound on) -> buzzer
render_tile_list();  copy_video_buf_to_vram();       // label_34 (0x5DE) + 0x556
wait(0x0D ticks);                                    // copy_xhl_to_0x022_or_loop_0x023, X=0x0D
slide(B=0xC);                                        // label_156 (0x500): scrolls the video buffer (M(0x2A:0x2B) += B) until it overflows
M(0x82)=5;  M(0x83)=0;                               // rounds left, wins   (0x649-0x64B; ldpx)
do {                                                 // label_198 (0x64C)  --- one round ---
    M(0x81)=0;                                       // player's guess (0=not yet)
    M(0x80)=M(0x246);  M(0x84)=8;                    // 0x246 = number of wait frames (stage; baby=1)
    if (rng_carry(M(0x245)))   { /* wins: keeps */ }            // label_282 (0x900): C = (M(0x05A)+A+1 > 15), A=M(0x245)
    else { M(0x80)=M(0x247); M(0x84)=0; }            // loses: 0x84=0
    // M(0x84)!=0 <=> round won. P(win)=M(0x245)/16 (baby: 8/16)  (M(0x05A)= free-running counter incremented in the ISR 0x182)
    M(0x5E)=5; anim_select(); M(0x26..0x29)->buttons;
    M(0x57)=0xF (timeout)  -- 0x665-0x666
    for(;;){                                         // label_200 (0x667)
        sound_cmd(0x97);                              // 0x667-0x668 (if sound on)
        clear_page_0x100(); anim_step(); draw_guess_arrow(); copy_buf_and_render_misc(); buttons=read();
        if (buttons & 1 /*R*/ || M(0x57)==0) goto exit_game;     // label_207
        if (M(0x81)==0) { if(!(buttons&6)) continue; M(0x81)=buttons; }   // guess: 2=M(right) 4=L(left)
        if (--M(0x80) != 0) continue;                // waits M(0x80) frames after the guess (label_201)
        break;
    }
    // resolution (0x67D-0x695)
    sound(0x94);  clear_page_0x100();
    B = M(0x84); if (M(0x81)&4 /*L*/) B ^= 8;        // drawn direction = result XOR guess
    M(0x3A)=0,M(0x3B)=1;  draw_turn(A=?,B);          // call label_128 (0x4EE, pg3)
    draw_guess_arrow(); copy_buf_and_render_misc(); wait(0x29 ticks);
    if (M(0x84)==0) lose_feedback(); else { M(0x83)++; win_feedback(); }
} while (--M(0x82) != 0);                            // label_204 (0x697)
// result screen (0x69B-0x6B4)
tilelist = label_334 template {18,FF,1D,FF,00,0F,00,FF}; M(0x98)=wins; M(0x9C)=5-wins;   // face / ♡ / "wins ? losses" (digits = tiles 0..9)
sound(0xE5); render_tile_list(); copy_video_buf_to_vram(); wait(0x52);
if (wins < 3) lose_feedback();                       // label_205
else { M(0x41)=min(M(0x41)+4,0xF); win_feedback(); } // label_331 (0xCE5): +1 happiness heart (4 nibbles = 1 heart)
// label_206 (0x6B6)
weight -= 1  (BCD, flag D):  M(0x46)+=9; M(0x47)+=9+C;  clamp_weight();   // 0x99 BCD = -1 mod 100
if (M(0x29) & 1 /*R*/) goto exit_game;
if (event_check() == Z) goto label_197;              // call label_357 (pg F): no pending event -> plays another game
exit_game: sound(0x94); pset 5; jp label_159          // label_207 (0x6C5) (deselects the menu)
```
Confirmed on the emulator: `M(0x82)` 5→4→…, `M(0x81)` = 4 when L is pressed, `M(0x84)` 8→0 (lost), `M(0x83)` 0→1 on a win; weight (5, min=max of the baby) goes back to 5 by the clamp.

Helper functions (all only called by this game):
* `0x6C8–0x6CC` `win_feedback` (label_208): sound `Y=0x83`; `A=7, Y=6` → `jp label_210`.
* `0x6CD–0x6D0` `lose_feedback` (label_209): sound `Y=0x9E`; `A=8, Y=3` → label_210.
* `0x6D1–0x6D3` label_210: `B=5; pset 8; jp label_273` (0x8A9) = `play_pet_animation(A=anim id, B=5 (time?), Y=variant)`.
  Animations seen: A=2 eat, A=6 refuse (shake), A=7 happy, A=8 sad/ouch (also discipline, medicine).
* `0x6D4–0x6E4` `draw_guess_arrow` (label_211): if `M(0x81)!=0`: tile `0x26` (arrow ◄, L) at buffer 0x180 or `0x27` (►, M) at 0x1B0 via `misc_render(B=2)`; otherwise nothing.
* `0x6E5–0x6F5` `clamp_weight` (label_214): weight `V=[0x47:0x46]` (2 BCD digits) clamped to `[min,max]` where `min=[0x23D:0x23C]`, `max=[0x23F:0x23E]` (stage table; baby 05/05):
  ```c
  if (V < min) V = min; else if (V >= max) V = max;   // (V==max writes max, same thing)
  ```
  (uses `clear_0x07D`/`set_f_0x07D` around the copy). Callers: 0x6BE, 0x760 (`jp` from `add_weight`), 0xDFF (`jp`, outside the range).
* `0x6F6–0x6FD` `cmp_weight_bound` (label_218): compares `V` (0x46/0x47) with the pair pointed to by Y (`my`); returns C/Z like a 2-digit `cp` (compares the high digit; if equal, the low digit at `Y-1`).
* 0x6FE–0x6FF: `nop7`.

Game data (stage RAM, copied from a table by the evolution code, outside the range): `M(0x245)`=win chance/16 (baby 8), `M(0x246/0x247)`=wait frames after the guess (baby 1/1), `M(0x248) bit0` (animation variant when eating, see food).

## 0x710–0x755 `food_menu` (label_220 / 221 / 223 … 229)
Food icon (n=1). 2-item menu ("meal" / "snack"), can feed several times until R/timeout.
```c
if (M(0x04A)&8) goto back_to_menu;                    // sleeping  (label_222 -> label_160)
for(;;){                                              // label_221 (0x712)
    M(0x78) = M(0x73);                                // initial cursor = last choice
    tilelist[0x90..0x97] = {FF,28,29,2A,FF,2B,2C,2D}; // label_308 (0xBE8, pg B): two 3-tile labels (0x28-0x2A "meal", 0x2B-0x2D "snack"; kana?)
    r = two_item_menu(timeout=0xA);                   // call label_352 (0xE5A, pg E): C=1 cancelled/timeout, otherwise A=0|1
    if (C) { if (Z==0) goto idle /*label_159*/; else goto back_to_menu /*label_160*/; }  // R: back to the menu; timeout/event: idle
    M(0x73) = A;                                      // label_223 (0x722) remembers the choice
    if (A == 0) {                                     // MEAL
        Y = 0xC;
        if ((M(0x048)&8) || M(0x209) != 0 || M(0x040) == 0xF) { anim_play(A=6,B=5,Y=0xC); continue; }   // refuses (label_228)
        M(0x040) = min(M(0x040) + 4, 0xF);            // label_331: +1 hunger heart
        add_weight(1);                                // label_230
        Y = 8;
    } else {                                          // SNACK
        M(0x041) = min(M(0x041) + 4, 0xF);            // +1 happiness heart
        if (!(M(0x048)&8)) { dec3(0x20D..0x20F) saturating at 0 (label_324, pg C, with 0x07D off); }   // (?) 3-digit counter
        add_weight(2);
        Y = 0xA;
    }
    if (M(0x248) & 1) Y++;                            // 0x749-0x74E animation variant
    anim_play(A=2, B=5, Y);                           // eat
}
```
Verified: meal `M(0x040) 0→4`, snack `M(0x073)=1`, `M(0x041) 0→4`, `M(0x20D) 6→5`, `M(0x05E)=2`.
Notes: `M(0x78)` = initial cursor passed to `two_item_menu`; `M(0x73)` memory of the last choice (0=meal,1=snack).
Callers: 0x702 (table). Calls: `label_308` (0xBE8), `label_352` (0xE5A), `label_331` (0xCE5), `label_324` (0xCC8), `label_273` (0x8A9), `label_230`.

### 0x756–0x760 `add_weight` (label_230)
`A` = grams/ounces to add (1 meal, 2 snack). In decimal mode (D): `V=[0x47:0x46]; V += A; if (V > 99) V = 99;` and `jp label_214` (clamp). Returns to the caller of `label_214`. Callers: 0x736, 0x747.
```c
V = BCD([0x47:0x46]) + A;   // D flag on: add mx,a ; adc mx,0
if (carry) V = 0x99;       // saturates at 99
clamp_weight();            // jp label_214
```

## 0x792–0x7BF 8x8 tile renderer
### 0x792–0x7A2 `render_tile_list` (label_233)
Draws **8 tiles** (a whole 4+4 text screen) from the list at `M(0x090..0x09F)`: each tile = 2 nibbles (A=lo, B=hi) ⇒ id = `B*16+A`.
Destination: `X = {XP=1, XH=M(0x3B), XL=M(0x3A)}` (pointer into the video buffer 0x100–0x1FF; `label_30`/`label_34` set 0x3A:0x3B=0x40 ⇒ 0x140). After 4 tiles it does `X += 0x40` (`adc xh,4`) for the 2nd strip.
Callers: `label_34` (0x5DE, via `jp`), 0xE72 (2-item menu), 0x0E1. Uses `XL/XH` as a live pointer; `Y` sweeps 0x090.

### 0x7A3–0x7A4 `fetch_and_misc_render`: `A=M(Y++); B=M(Y++)` and falls into `misc_render`.
### 0x7A5–0x7B7 `misc_render(A,B,X)`  (agg23's label: `misc_render`)
Draws tile `n=B*16+A` (`n<0x40`) as 16 nibbles starting at `M(X)` (X advances 16). `n>=0x40` (B≥4, e.g. FF) ⇒ `clear_16_addrs` (erases 16 nibbles).
Implementation: `m0=(A&1)*8; m1=(n>>1)&0xF; m2=6+(n>>5)`; `pset 0; jp render_asset (0x000)` which does `jpba` to the graphics table at 0x1000.
**Tile data**: ROM `0x1600 + 8*n` (64 tiles, 0x1600–0x17FF), 8 `lbpx` words ⇒ 8 columns × (low nibble = rows 0–3, high nibble = rows 4–7). Verified: tile 0x00..0x09 digits, 0x0F ?, 0x18 face, 0x1C full heart, 0x1D empty heart, 0x26 ◄, 0x27 ► (also menu cursor), 0x28–0x2D menu labels.
Returns through the tile's final `retd` (the call is a `jp`, so the return goes to the caller of `misc_render`).
Callers (inside 0x600–0x7FF): 0x6E3 (`draw_guess_arrow`), 0x79A–0x7A2 (render_tile_list); outside: 0x3D1,0x419,0x428,0x431,0x45E,0x55C,0x560,0x5C5 and `label_233`.
### 0x7B8–0x7BF `clear_16_addrs` / `clear_8_addrs_ret`
`clear_16_addrs`: 4×`lbpx 0` + falls into `clear_8_addrs_ret` (3×`lbpx 0` + `retd 0`) ⇒ clears 16 (or 8 if entered at 0x7BC) nibbles starting at `M(X)` and returns. Callers: `misc_render` (jp nc), 0x5C7 (call 0x4B8), 0x5CE (call 0x4BC).

## 0x7C0–0x7D4 `set_menu_icon` (label_238; entry `springboard_label_238` = 0x5ED, and `label_38` = 0x5EC with A=0)
Input: `A` = highlighted icon (0 = none, 1..8 = icon 0..7). Writes the 8-bit mask to `M(0x02C)`,`M(0x02D)` (low nibble, high) via the table at 0x7D8, then turns on the "attention" icon (bit 7 = `M(0x02D)|=8`) and calls the part that writes to the LCD.
```c
mask = (A==0) ? 0 : 1 << (A-1);   // table 0x7D8, read by label_241 (jpba at 0x7D5: B:A = A+0x8 + 0xD00 -> 0x7D8+A)
M(0x02C)=mask & 0xF; M(0x02D)=mask >> 4;
if (!(M(0x04A)&8)) { if (M(0x208) || M(0x209)) M(0x02D) |= 8; }     // awake: attention lit if there is a call (hunger/happiness/sickness = 0x208) or discipline (0x209)
else               { if (M(0x205) < 4)          M(0x02D) |= 8; }     // sleeping: attention lit while 0x205<4 (?)
write_icons();   // falls to label_242
```
Callers: `label_88` (0x294, A=0), 0x527/0x53E/0x555 (menu), `label_38` (0x374, 0x509, 0x983).
### 0x7D5–0x7D7 `icon_mask_lookup` (label_241) and table 0x7D8–0x7E0
`add a,8; adc b,0xD; jpba` ⇒ jumps to `0x7D8+A` (A=0..8); each `retd` writes (lo,hi) to `M(X),M(X+1)` and returns:
| A | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|---|
| retd | 0x00 | 0x01 | 0x02 | 0x04 | 0x08 | 0x10 | 0x20 | 0x40 | 0x80 |
(value = icon mask; low nibble → `M(0x02C)`, high → `M(0x02D)`.)
### 0x7E1–0x7FE `write_icons` (label_242)
Reads `A=M(0x02C)`, `B=M(0x02D)` and writes to the LCD segment nibbles (XP=E): `M(0xE10)=A` (icons 0–3 = seg 8 with 0–3), `M(0xEB9)=B` (icons 4–7 = seg 28 with 12–15) and rotated copies (`rrc a`/`rlc b`) at `0xE22,0xE24,0xE26` and `0xECB,0xECD,0xECF` (duplicated segments of the same icon, see the `IC n -> ...` comment in `tamalib/hw.c`). (Note: `ld x,0x10` with XP=E is the address **0xE10**, not RAM 0x010.)
Callers: `label_83` (0x279, `call 0x4E1`) and `label_238`. 0x7FF: `nop7`.
