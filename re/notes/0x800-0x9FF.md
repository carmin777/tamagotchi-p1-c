# ROM 0x800–0x9FF (pages 8 and 9)

Source: `tools/asm.py 0x800 0x9FF` + cpu.c. Dynamic verification with `harness/trace` (saved state = live baby, age 0).
Conventions: `Mxxx` = RAM nibble; `mN` = RAM[0x00N] (scratch registers of page 0, `ld m0,a`).
`B:A` = byte with B in the high nibble (used by `jpba`). Bytes in RAM are nibble little-endian
(`lbpx mx,0xNN` / `retd 0xNN` writes M(X)=NN&F, M(X+1)=NN>>4 and X+=2; `lbpx` continues, `retd` also returns).
Buttons (M026/M028 = state; M027/M029 = latch of "pressed since the last read"): bit0=R, bit1=M, bit2=L
(confirmed: M advances the status page; `copy_0x026_7_to_8_9` returns A=old M026, B=old M027).

Summary of what the range is: (1) the **Status** screen (icon 6), (2) the **overlay-animation player** (`play_overlay_anim`, food/Z/skull/star
icons on top of the pet), (3) the **dissolve to black** effect, (4) **drawing the pet's sprite** (2 16x8 tiles, with mirroring),
(5) the boot wait (egg), (6) tables of **X-position scripts of the pet**.

Graphics tile sizes (confirmed with "Useful Addresses.md"): pet sprites = 16 words (0x1000+16*id, id 3 = 0x1030);
"misc" glyphs (digits, texts, icons) = 8 words (0x1600+8*id, id 0..9 = large digits, 0x18 baby, 0x19 "yr", 0x1A scale, 0x1B "OZ",
0x1C full heart, 0x1D empty, 0x2E-0x30 "Hungry", 0x31-0x33 "Happy", 0x34-0x37 "Discipline", 0x10-0x13 bread (whole/1st bite/2nd/empty),
0x14-0x16 snack, 0x1E/0x1F poop stink, 0x20/0x21 Z, 0x22 skull, 0x23 success sparkle, 0x24/0x25 anger).
Video buffer = RAM 0x100–0x1FF (page 1); `copy_video_buf_to_vram` (0x556) copies from {1,M02B,M02A} (M02A:B = 0x40 → 0x140) to the LCD.
"Upper" half of the buffer = 0x140–0x17F (4 tiles of 16 nibbles = 8 columns each), "lower" = 0x1C0–0x1FF (+0x80).

## 0x800–0x807  `dither_masks`  (agg23: "Jump table for choose_x_word_244")
Table of 8 `retd`: index 0..7 → byte 0x20, 0x08, 0x01, 0x40, 0x02, 0x80, 0x10, 0x04 (permutation of the 8 bits; fill order of the dissolve).
Read by `dither_mask_lookup`. Logic data (visual effect), not graphics.

## 0x808–0x80C  `dither_mask_lookup`  (agg23: `choose_x_word_244` + `jp_a`)
Input: A = index (needs the caller's `pset 8`); X = destination. Output: M(X)=byte&F, M(X+1)=byte>>4 (X+=2).
```c
void dither_mask_lookup(u4 a) { if (a & 8) { M[x]=0; M[x+1]=0; } else { /*jpba 0x800+a*/ M[x..x+1] = dither_masks[a]; } }
```
Caller: `or_dither_pattern` (0x917). Nothing else.

## 0x80D–0x813  `clear_quads_p1`  (agg23: `label_245`/`label_246`)
Sets XP=1; clears `4*A` nibbles starting at X (A=0 → 16 iterations = 64 nibbles). Input: A, X (low 8 bits). `ret`.
```c
void clear_quads_p1(u4 a, u8 x) { u4 n = a ? a : 16; do { RAM[0x100+x..+3] = 0; x += 4; } while (--n); }
```
Callers: `label_155` (0x4EA, 0x4EE, 0x4F7: clears 0x140.., 0x1C0.., 0x170.. when building the clock/icon-0 screen).

## 0x814–0x835  `status_screen`  (agg23: `label_247`..`label_252`)
Routine of the **Status icon (6th)**: dispatched by table 0x700 (entry idx 6: `pset 8; jp label_247` at 0x70C/0x70D), confirmed by running the harness (L×6, M).
Shows 4 pages in a cycle; M or R advance; L exits; exits by itself after 15 s (M057 = 0xF, decremented at 1 Hz by `clock_timer_int`)
or if `label_357` (0xF00, event checker; returns Z = nothing pending) reports an event (M05C != 0).
RAM: M080 = page (0..3). M081 = flag "draw the gauge frame" (cleared by `status_build_page`). M057 = timeout (s).
```c
void status_screen(void) {            // 0x814
    M[0x80] = 0;
    for (;;) {                        // label_248
        status_build_page();          // 0x836: fills the table of 8 ids in M090..M09F and M081
        label_34();                   // 0x5DE: M02A:B = 0x40 (buffer origin), M03A:B = 0x40; calls label_233 (0x792) -> draws the 8 glyphs
        if (M[0x81] != 0) draw_discipline_gauge();     // 0x867
        copy_video_buf_to_vram();     // 0x556
        read_buttons();               // 0x521
        M[0x57] = 15;                 // timeout in seconds
        for (;;) {                    // label_250
            read_buttons();           // A=old M026, B=old M027 (latch)
            if (M[0x57] == 0 || (B & 1)) goto exit;      // timeout or L
            if (!(B & 6)) continue;                       // waits for M or R
            beep(0x94);               // 0x5BB: if M07B: M032=0; M036:37=0x94; M058=A; M059=F
            M[0x80] = (M[0x80] + 1 < 4) ? M[0x80] + 1 : 0;
            if (event_check_0xF00()) goto exit;           // pset F; call 0xF00; jp z,label_248
            break;                    // goes back to rebuild the page
        }
    }
exit:
    beep(0x94); goto main_idle_label_160;                 // pset 5; jp 0x51A (0x835)
}
```
Note: `read_buttons` clears M027; B keeps the value read.

## 0x836–0x842  `status_build_page`  (agg23: `label_253`)
XP=0, YP=0; A=M080; M081=0; computes B:A = (page-1)+0x30 (page 0 → 0x3F; 1→0x40; 2→0x41; 3→0x42) and `jpba` within page 8 itself
→ table of 4 `jp` at 0x83F..0x842: page 0→`label_254`, 1→`label_257`, 2→`label_264`, 3→`label_265`. X=0x90 on entry.
Each subroutine fills **8 glyph ids (1 byte/id, 2 nibbles, in M090..M09F)**; `label_233` (0x792) draws 4 on top (X=0x140+16*i)
and 4 below (+0x80). Id byte: low nibble = id&F, high nibble = id>>4; high >=4 (e.g. 0xF) = blank tile (`clear_16_addrs`).

### 0x843–0x85B  `status_page_age_weight`  (`label_254`..`label_256`)  — page 0
```c
M90..9F = { 0x18 /*baby*/, dig(M055), M054, 0x19 /*"yr"*/,  0x1A /*scale*/, dig(M047), M046, 0x1B /*"OZ"*/ };
// dig(d) = (d==0) ? 0xF0 /*blank, leading-zero suppression*/ : d
```
=> **M054:M055 = age (2 digits, M054 units), M046:M047 = weight (2 digits)**. (Dump: M046=5, M047=0, age 0.)

### 0x85C–0x866  `status_page_discipline`  (`label_257`) — page 1
Ids {0x34,0x35,0x36,0x37} ("Discipline") + 4 blanks 0xFF; `M081 = 1` (requests `draw_discipline_gauge`).

### 0x867–0x882  `draw_discipline_gauge`  (`label_258`, `label_260`..`label_263`; sub `label_261`/0x87D)
Draws the gauge frame in the buffer 0x1C2..0x1FF and fills M043−1 segments.
```c
XP=1;
RAM[1C2..1C3]=0x3D; fill14(0x1C4, 0x42); RAM[1E0..1E1]=0x43; fill14(0x1E2,0x42); RAM[1FE..1FF]=0x3D;  // fill14 = 14 words 0x42 (nibbles 2,4)
n = M[0x43] ? M[0x43] : 1;
for (i = 1; i < n; i++) { RAM[0x1C6 + 4*(i-1)] = 0x5A /*nibbles A,5*/; }   // 14 segments max.
```
=> **M043 = discipline (0..F)** (segments = M043−1). Exact pixel geometry (?).

### 0x883–0x888  `status_page_hunger` (`label_264`) — page 2
Ids {0x2E,0x2F,0x30 ("Hungry"), 0xFF}; Y=0x40; falls into `draw_hearts`.
### 0x889–0x88B  `status_page_happy` (`label_265`) — page 3
`pset B; call 0xBF8` (writes {0x31,0x32,0x33 ("Happy"),0xFF} into M090..097); Y=0x41; falls into `draw_hearts`.
### 0x88C–0x89D  `draw_hearts`  (`label_266`..`label_270`)
Input: Y → value v (M040 hunger, M041 happy), X at the 5th id. Writes 4 ids: 0x1C (full)/0x1D (empty).
```c
n = (v >= 0xF) ? 4 : ((v + 1) >> 2) & 3;      // v 0-2→0, 3-6→1, 7-10→2, 11-14→3, F→4 hearts
for (i=0;i<4;i++) { *ids++ = (n==0) ? 0x1D : 0x1C; if (n) n--; }
```
=> **M040 = hunger, M041 = happiness** (validated: M040=4 → 1 full heart; M041=0 → 0).

## 0x89E–0x8FF  Overlay-animation player
Entry points (all end in `label_274`/loop `label_275`):
- `play_overlay_anim_autostate` (`label_271`, 0x89E): Y=0 (script 0); calls `label_176` (0x596) which chooses M05E (1 normal, 9 if the high bit of M048, 3 if the high bit of M04A) and restarts the pet's animation if it changed. Callers: 0x351, 0x371 (evolution, `label_112`).
- `play_overlay_anim_y0` (`label_272`, 0x8A8): Y=0, falls into `label_273`. Callers: 0x621, 0xFF5.
- `play_overlay_anim` (`label_273`, 0x8A9): **A = state of the pet's animation (→ M05E), B = maximum time in s (→ M057), Y(yh:yl) = overlay script index (0..0xC)**.
  Callers: 0x60B, 0x6D3, 0x754, 0xAED, 0xD91, 0x3D6 (`label_124`), etc.
  (A,Y) seen: (8,3) refusal/anger, (7,6) happy/success, (2,0xA/0xB) eating snack, (6,..) etc. (semantic names ?).

```c
void play_overlay_anim(u4 a, u4 b, u8 y) {            // 0x8A9
    M[0x5E] = a;  /*xp=0*/            // (271 recomputes via label_176)
    M[0x57] = b;                        // timeout in seconds (decremented at 1 Hz)
    {M[0xA6],M[0xA7]} = overlay_script_index[y];       // jp_table_0xE00 at 0xE00: pointer (byte) to the script at 0xE0E..0xE59
    M[0xAA] = 0;
    pet_anim_init();                    // 0x465 (label_142): clears M05F, M066/67; chooses scripts by (M05D,M05E)
    read_buttons();
    for (;;) {                          // label_275 (0x8B9)
        clear_page_0x100();             // 0x540
        pet_anim_tick();                // 0x486 (label_145): advances the path/position scripts and draws the pet
        if (M[0xAA]-- == 0) {           // add mx,0xF; carry<=>M[AA]!=0
            p = M[0xA6] | M[0xA7]<<4;  M[0xA6..A7] += 2;       // 8 bits
            fetch step bytes: w0 -> M[A2:A3], w1 -> M[A4:A5], [w2 -> M[A6:A7] (new pointer = loop)]   // jp_table_0xE00(p)
            M[0xA8] = w0 & 0xF;  M[0xA9] = (w0 >> 4) & 3;       // glyph id = w0 & 0x3F
            M[0xAA] = (w0 >> 6) & 3;                             // the step lasts M[AA]+1 iterations
        }
        if (!(M[0xA8]==0xF && M[0xA9]==3)) {                    // id 0x3F = do not draw
            x = w1;                                              // position = address in buffer p1 (xh:xl = w1)
            if (M[0x5D] == 1) {                                  // (stage 1 = baby, see note) remaps
                xh = xh ? (xh|8) : 0;  c = (xl+8)>15; xl=(xl+8)&15;
                s = xh + 0xF + c; xh = s & 15;
                if ((xh|8) == 0xF) xh = (xh+1)&15;
            }
            misc_render(id = M[A8] | M[A9]<<4, X = 0x100|xh<<4|xl);   // fetch_and_misc_render 0x7A3
        }
        copy_buf_and_render_misc(); copy_video_buf_to_vram();   // 0x554
        read_buttons();                 // A,B = old M026/27
        if (M[0x57] == 0) return;       // time is up (also: B==0 → only 1 frame)
        if (M[0x74] == 0) continue;     // M074 != 0 => allow cancelling by button (?)
        if ((B & 7) == 0) continue;
        beep(0x94);  return;            // 0x8FE
    }
}
```
Notes:
- The loop has no explicit wait: the pace comes from the CPU's slowness (each iteration: clear 256 nibbles + draw ≈ hundreds of ms; measured: 14 iterations in a few s). Script durations are in **iterations**, not seconds.
- Effect of the M05D==1 remapping (confirmed M05D=1 in the "baby" state): X' = X+8 nibbles and, if xh≠0, shifts to the other bank (+0x78 effective; xh=0 stays at xh=0). Intention: repositioning overlays for the small pet (?).
- M074: written at 0x378 (=0), 0xFF8 (=F), 0x1213 (=0); the "button cancels" semantics is a hypothesis (?).
- Overlay script format (0xE0E..0xE59, outside the range; index table at 0xE00): each step = 2 bytes `[w0][w1]`, optional 3rd byte = new pointer (low byte, page E) → loop. Chain = `lbpx`.. `retd` (the `retd` ends it). Decoded:

| idx | ptr | steps (w0 w1) → (glyph, rep, position) | use |
|---|---|---|---|
| 0 | 0xE0E | FF 50 loop E0E | empty |
| 1 | 0xE11 | 60 30 / 61 30 loop E11 → glyphs 0x20/0x21 (Z) at 0x130 | sleeping |
| 2 | 0xE16 | FF50, FF50, 5E A8 / 5F A8 loop E1A → 0x1E/0x1F at 0x1A8 | stinky poop |
| 3 | 0xE1F | 65 30 / 64 30 loop E1F → 0x25/0x24 at 0x130 | anger |
| 4,5 | 0xE24 | 62 30 / 7F 50 loop E24 → 0x22 skull blinks | sick |
| 6 | 0xE29 | 7F 50 / 63 30 loop E29 → 0x23 sparkle blinks | success |
| 7 | 0xE2E | D7 B0 loop → 0x17 fixed at 0x1B0 | (?) |
| 8 | 0xE31 | 10 00, 10 80, D1 80, D2 80, D3 80 loop → bread: whole, 1st, 2nd bite, empty | eating bread |
| 9 | 0xE3C | 10 00, 10 80, 52 80, 53 80 loop | bread (short) |
| 10 | 0xE45 | 14 00, 14 80, D5 80, D6 80 → jump E0E | snack |
| 11 | 0xE4E | 14 00, 14 80, 56 80 → jump E0E | snack (short) |
| 12 | 0xE55 | 10 00, D0 80 loop E57 | bread idle |
(w0: bits0-5 glyph, bits6-7 extra repetitions; w1: address in buffer p1.)

## 0x900–0x905  `rand_chance`  (agg23: `label_282`)
```c
bool rand_chance(u4 a) { if (a == 0) return 0 /*C=0*/; M[0x5A] = M[0x5A] + a + 1; return carry; }
```
M05A is a free-running counter incremented on every prog timer tick (256 Hz) in `prog_timer_int` (0x181) → source of randomness; P(carry)≈(a+1)/16, and it advances the "seed". Caller: 0x659 (`label_198`, routine of icon 3, A=M245).

## 0x906–0x912  `screen_dissolve`  (agg23: `copy_video_buf_8x`, via `jp_copy_video_buf_8x` 0x3FC)
Dissolve in 8 steps: at each step ORs a mask into the whole page 0x100, copies to the LCD, waits 1 prog timer tick; at the end clears the buffer.
```c
void screen_dissolve(void) {      // m2 = step, m3 = remaining (8)
    for (m2=0, m3=8; m3; m2++, m3--) { or_dither_pattern(m2); copy_video_buf_to_vram(); delay_ticks(0x01); /* copy_xhl_to_0x022_or_loop_0x023, X=1 */ }
    clear_page_0x100();
}
```
Callers: 0x34E, 0x352 (evolution `label_112`), 0x375 (death `label_116`). Side effect: m2=8, m3=0.

## 0x913–0x927  `or_dither_pattern`  (agg23: `or_0x100_ab`)
Input: m2 = step (0..7). `dither_mask_lookup(m2)` → M000=lo, M001=hi of the byte; then, for the 256 nibbles of 0x100–0x1FF:
`buf[4k]|=lo; buf[4k+1]|=lo; buf[4k+2]|=hi; buf[4k+3]|=hi`. Accumulating all 8 steps every nibble becomes 0xF (black screen).

## 0x928–0x97E  Drawing the pet's sprite (2 stacked 16x8 tiles)
Callers: `pet_anim_tick` (0x4CA → 0x928, 0x4E1 → 0x939), `label_128/127` (0x3F4/0x3FB: death/ghost screens, draw a pair A=part,B=flip).
- `draw_pet_upper` (`label_288`, 0x928) **A = part index (nibble), B = flags (bit3 = mirror)**; `draw_pet_lower` (`label_289`, 0x939): same using table 0xD00 (the lower half goes at X+0x80: the caller adds 8 to M03B beforehand).
```c
// label_288; label_289 identical swapping 0xC00 for 0xD00
m0 = a; m3 = b;
{m1,m2} = table_0xC00[ M[0x5D] ];            // pointer (byte) per stage (jp_table_0xC00; entry 0xC00+stage)
{M[0x24],M[0x25]} = table_0xC00[ (m2<<4|m1) + m0 ];   // byte = tile id; indexes the 2nd level (offset+part)
M[0x25] ^= (m3 & 8);                           // bit3 of M025 = mirroring flag
render_pet_tile();                             // label_291
```
- `render_pet_tile` (`label_290`/`label_291`, 0x949–0x97E):
```c
id = ((M[0x25] & 7) << 4 | M[0x24]) + 3;   if (id >= 0x80) return;   // m2:m1 = id; m0 = 0
render_asset(id, X = 0x100 | M[0x3B]<<4 | M[0x3A]);   // 0x500 (calz): tile at 0x1000 + 16*id into buffer p1
if (M[0x25] & 8) {                          // mirrors horizontally (16 columns of 2 nibbles)
    X = M3A:3B;  Y = X + 0x1E;
    for (i = 0; i < 8; i++) { swap(M[X],M[Y]); swap(M[X+1],M[Y+1]); X += 2; Y -= 2; }
}
```
M03A:M03B = X position of the sprite (address in buffer p1).

## 0x97F–0x98A  `boot_wait_for_start`  (agg23: `label_294`, `loop_294`)
Initial wait screen (egg): calls `label_232` (0x761: initializes the game state: M05D=0, M05E=1, M040/M041=1, M046=5, M054/55=0, M048..=..., M015=5, M016/17=0x28 etc.), `pet_anim_init`, `label_38`,
and enters a loop: `clear_page_0x100(); pet_anim_tick()+draw (label_13 0x552); read_buttons();` until M029 bit1 (M) → `pset 5; jp label_167` (0x553: clock-setting screen).
Callers: 0x241/0x26A (post-reset), 0x58C.

## 0x98B–0x99A  `pos_script_index`  (table of 16 retd; used by `pet_anim_init`, 0x47A)
`pet_anim_init` computes `B:A = M1 + 0x8B` with M1 = high nibble of the byte of table 0xB00 (by M05D:M05E) and jumps (`pset 9; jpba`) to 0x900+B:A ⇒ low-byte pointer to the script:
idx → pointer: 0→9B, 1→9E, 2→B1, 3→BE, 4→C3, 5→CE, 6→D3, 7→DC, 8→E5, 9→EC, 10→F1, 11..15→00 (unused).
The `retd` writes the pointer into M06A:M06B.

## 0x99B–0x9FF  `pos_scripts`  (position/mirroring scripts of the pet)
Read by `pet_anim_tick` (0x496–0x4E0) — outside the range but the format is settled here. Each step = 2 bytes, optional 3rd = loop pointer (low byte in page 9):
```c
// per tick: if (--M[0x66:0x67] borrow) { p = M06A:6B; M06A:6B += 2; step = jp_table_0x980_2(p) -> M066:067 = w0, M068:069 = w1, [M06A:6B = w2]; M070 = M067; M067 = 0; }
// w0: low nibble (M066) = duration-1 in animation ticks; high nibble -> M070 = flags
//   M070 bit3: draw upper tile; bit2: draw lower tile; bit1: mirror upper (xor M063.bit3); bit0: mirror lower (xor M063.bit2)
//   (M063 comes from the path script 0xB00: bit1/bit0 choose M06F instead of M06E as the upper/lower part)
// w1: X position of the sprite (M06C:6D -> M03A:3B). bit0==0: absolute value; bit0==1: relative, delta = (w1 & 0xFE) (8 bits, e.g. 0xFB = −6, 0x07 = +6)
```
Dynamic verification (baby state): M06A:6B=0xB7, M068:69=0x0C, M066:67=0, M070=F, M06C:6D=0x0C ⇒ last step read = (F0,0C) of script 2.
Full decoding (step address: [w0 w1 (ptr)]):
| idx | start | steps |
|---|---|---|
| 0 | 99B | [CF 10] loop 9B (idle, flags C) |
| 1 | 99E | C0 12, C0 12, C0 14, C0 12, C0 12, C0 12, C0 14, C0 12, [C7 08] loop AE |
| 2 | 9B1 | C0 10, C1 FB(−6), F0 0C, C0 08, F2 07(+6), [C0 14] loop B1 |
| 3 | 9BE | C5 10, [C1 0E] loop BE |
| 4 | 9C3 | C0 10, C2 FD, F3 05, C1 FD, [F3 03] loop C3 |
| 5 | 9CE | C5 10, [D0 10] loop CE |
| 6 | 9D3 | C0 10, C3 FF, F7 03, [C2 FF] loop D3 |
| 7 | 9DC | C0 10, C2 FD, F5 05, [C1 FD] loop DC |
| 8 | 9E5 | C7 10, D3 10, [CB 10] loop E5 |
| 9 | 9EC | C7 10, [F7 10] loop EC |
| 10 | 9F1 | C0 10, C1 12, C0 10, C0 12, C0 10, C1 12, [C7 10] loop FD |
Note: the final loop of idx 10 points to 0xFD, i.e. it repeats only the last step (C7 10) — the "ptr" 0xFD/0xFF falls inside the last chain (confirmed: 0x9FD=`lbpx C7`, 0x9FE=`lbpx 10`, 0x9FF=`retd FD`).
Flag C(=1100) ⇒ draws upper+lower without mirroring; F ⇒ both mirrored (xor with M063); D = lower mirrored... (derived from the code; the meaning of each script — walk, jump, sleep etc. — depends on table 0xB00 and is still (?)).
