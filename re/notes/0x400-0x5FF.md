# ROM 0x400–0x5FF — pet animation, main screen, clock

Conventions: `M[a]` = RAM nibble; `{M[b]:M[a]}` = byte (a = low nibble). `XP:XH:XL` = 12-bit X pointer.
`pset N; call/jp s` = jump to `N*0x100+s`. `jpba` jumps to `{NP,B,A}` (jump table indexed by B:A, NP comes from the preceding `pset`).
`retd imm` = returns writing `imm&F` to M[X], `imm>>4` to M[X+1], X+=2 (used as an 8-bit data table).
`lbpx mx,imm` = writes 2 nibbles to M[X],M[X+1] and continues (does not return). The combination `lbpx…; retd` = long table entry.
Flags: C=bit0, Z=bit1, D=bit2, I=bit3 (`set f,8` turns IRQ on). Buttons (K0): bit0=R (cancel), bit1=M (confirm), bit2=L (select).
Machine evidence: traces in `out/sub400*/` (baby0.sav) — cited where used.

This range contains (a) the pet animation engine (`reset_pet_animation`, `step_pet_animation`), (b) pet screen overlays
(sleep/sick/poop), (c) the main screen loop with the icon menu, (d) the clock-setting screen, (e) clock drawing.
There are no game data tables in this range (only `nop7` padding at 0x4FE-4FF and 0x5FE-5FF; the tables used live at 0x98B, 0xA00, 0xB00, 0xBC0, 0xC00, 0x15E6).

## Video buffer model (needed to read everything below)
- Buffer in RAM page 1: 0x100–0x1FF = 64 columns x 16 rows, 2 nibbles/column (low nibble = top 4 rows of the 8-row block).
  - Upper half (rows 0-7): 0x100–0x13F = LEFT page (columns 0-31), 0x140–0x17F = RIGHT page (32-63).
  - Lower half (rows 8-15): 0x180–0x1BF = left, 0x1C0–0x1FF = right.
- `{M2B:M2A}` (0x02A/0x02B) = "view ptr" = offset (in nibbles) of the 32-column window that `copy_video_buf_to_vram` (calz 0x56) copies
  to the LCD (0xE00/0xE80): reads `0x100+ptr .. +0x3F` and `0x180+ptr .. +0x3F`. ptr=0x00 shows the left page; ptr=0x40 the right one;
  intermediate values = scrolling. `clear_page_0x100` (calz 0x40) clears everything and sets ptr=0; `label_30` (calz 0xCE) sets ptr=0x40.
- Game convention: the pet screen is drawn on the LEFT page; "modal" screens (clock, menus) on the RIGHT (ptr=0x40). Transition = scrolling
  (`scroll_view_left` / `scroll_view_right`, see below).
- 16-nibble tile ("8x8 tile"): `misc_render(B:A=v)` (0x7A5) draws 16 nibbles at M[X..X+15]: v<64; v>=64 erases. Graphic address:
  page 0x16 if v<32 else 0x17, offset `(v&0x1F)*8` (name table at the end of the file).

## 1. `draw_pet_screen_overlays` — 0x400–0x464 (agg23: `copy_buf_and_render_misc`; his comment "copies buffer to VRAM" is WRONG: it only draws into the buffer)
Called every frame of the pet screen after `step_pet_animation` (via `calz 0x54` = `calz_copy_buf_and_render_misc`, which then falls into
`copy_video_buf_to_vram`). Draws over the left page: blackout (light off), sleep Z, sickness skull, and the pile of poops.
Called by: 0x055 (stub calz 0x54), 0x50F, 0x635. Calls: `misc_render`(0x7A5), `check_0x04A_highbit`, `bit_high_at_0x048`, `one_a_xp`.
RAM: reads M[4B], M[4A], M[48], M[4D]; writes M[4A] (counter), M[7E] (frame counter), buffer 0x100–0x1BF, M[3],M[4] (temporaries).
```c
void draw_pet_screen_overlays(void) {
  if (M[0x4B] == 0) {                       // light off (?: 0x4B=1111 light on; cleared when the light is turned off, see 0x359 which sets F on waking)
    fill(0x100..0x13F, 0xF); fill(0x180..0x1BF, 0xF);        // black screen (erases the pet that was drawn)
    if (M[0x4A] & 8) {                      // sleeping (M4A=F when falling asleep/ 0 on waking: 0x30C, 0xF1F)
      M[0x4A] = (M[0x4A] + 1) | 8;          // 8..F cyclic (anim)
      misc_render(v = 0x20 + ((M[0x4A]>>1)&1), at X=0x120); // 0x1700/0x1708: "Z" on black
    }
    return;
  }
  if (M[0x4A] & 8) {                        // sleeping, light on
    M[0x4A] = (M[0x4A] + 1) | 8;
    misc_render(v = 0x3A + ((M[0x4A]>>1)&1), at X=0x130);   // 0x17D0/0x17D8: "Z" on light
  } else if (M[0x48] & 8) {                 // sick (M48 bit3: skull)
    misc_render(v = 0x22, at X=0x130);                      // 0x1710 skull
  }
  // poops
  M[0x7E]++;                                // frame counter (4 bits, free-running)
  M[4] = 0xE + ((M[0x7E]>>1)&1);            // 0xE/0xF -> toggles every 2 frames
  M[3] = n = min(M[0x4D], 8);               // number of poops (M4D, max 8)
  if (n >= 3) {                             // shifts the left page to the left to free columns
    k = ((n-3)>>1) + 1;                     // n=3,4->1  5,6->2  7,8->3
    memmove(0x100..0x13F  <- 0x100+16k ..), memmove(0x180..0x1BF <- 0x180+16k ..);   // 64 nibbles each; k*8 columns
  }
  // draws n poop tiles (v = 0x10 + M[4] = 0x1E/0x1F -> 0x16F0 "poop →" / 0x16F8 "poop ←") at
  // X = 0x1B0,0x130,0x1A0,0x120,0x190,0x110,0x180,0x100 (in that order: 1st bottom right, 2nd above it, ...)
}
```
Details: the shift reads beyond 0x13F/0x1BF (for k>=1 it pulls garbage from the right page), but that region is overwritten by the poop tiles
(n>=3 -> tiles at 0x1B0,0x130,0x1A0 cover k=1; n>=5 covers k=2; n>=7 covers k=3). Hypothesis (?): the pet is drawn already accounting for the
shift (positions in the movement tables) — not verified. M4A: sleep nibble: bit3 = sleeping, bits0-2 = phase of the Z animation
(confirmed: 0x30C sets F when falling asleep, 0xF1F sets 0 on waking, together with M4B=F).
Traces: M[7E] rises 1 per frame (~0.45 s) and M[4] toggles E/F every 2 (out/sub400c/writes.tsv, pc 0434/0439).

## 2. `reset_pet_animation` — 0x465–0x481 (agg23 `label_142`); thunks 0x482–0x485
Restarts the animation engine for the current (stage, anim type) pair. Input: M[5D] = life stage (0=egg, 1=baby, … ; evidence:
egg M5D=0, baby M5D=1 in the dumps out/boot_egg.sav / baby0.sav), M[5E] = animation set (1=normal, 3=sleeping, 9=sick, 5 = other,
see `select_pet_anim_set`). Called at: 0x21F, 0x36E, 0x5A4, 0x630, 0x663, 0x8B7, 0x982, 0xFFC.
```c
void reset_pet_animation(void) {
  M[0x5F] = 0;                              // pose timer
  M[0x66] = M[0x67] = 0;                    // movement timer
  idx = (M[0x5D] << 4) | M[0x5E];
  {M[0x6F]:M[0x6E]} = TBL_0xA00[idx];       // 2 sprite ids (nibbles): 6E = "frame 0", 6F = "frame 1"   (call 0xABD = jpba, page A)
  {M[1]:M[0]}       = TBL_0xB00[idx];       // M0 = pose script index (tab 0xBC0), M1 = movement script index (tab 0x98B)
  {M[0x6B]:M[0x6A]} = TBL_0x98B[M[1]];      // initial pointer of the MOVEMENT script (low byte, page 9)   -> thunk 0x482 (pset 9; jpba)
  {M[0x65]:M[0x64]} = TBL_0xBC0[M[0]];      // initial pointer of the POSE script (low byte, page B)        -> pset B; jpba
}
```
(The index `0x98B+M1` comes from `a=M1+0xB, b=8+carry`; `0xBC0+M0` from `b=0xC`.) The X destinations are 0x6E, 0x00, 0x6A, 0x64 — the `retd`s of the
targets write straight there. M[0..1] are only temporaries. It does not clear the position {M6D:M6C}.
Example (traces, baby): TBL_A00[0x11]=0x15 -> sprites 5 and 1; M64 oscillates 0xA/0xB/0xC following the pose script (out/sub400c).

## 3. `step_pet_animation` — 0x486–0x4E2 (agg23 `label_145`); thunks 0x4E3–0x4E6
One step per frame: advances the two scripts (pose and movement), computes the position and draws the pet (upper and lower half) in the buffer
at `{M3B:M3A}` (page 1). Called from: 0x053 (`label_13`), 0x50D, 0x633, 0x66B, 0x8BB. Calls: `jp_table_0xB00_2`(0x4E3), `jp_table_0x980_2`(0x4E5),
`label_288`(0x928: draws the upper half), `label_289`(0x939: lower half) — both consult tables 0xC00/0xD00 by M[5D] and call `render_asset`.

State (RAM, all nibbles):
| addr | meaning |
|---|---|
| 5F | pose timer (frames left; duration = delay+1) |
| 62 | low nibble of the pose byte read = delay (goes to M5F); 63 = high nibble = pose flags |
| 64/65 | pointer (8 bits) into the pose script, page 0xB (`{65:64}`) |
| 66/67 | counter (8 bits) of the movement step; M67 is cleared after loading and its value goes to M70 |
| 68/69 | movement argument of the current step (`{69:68}`): bit0 = relative; rest = position/delta |
| 6A/6B | pointer into the movement script, page 9 (advances by 2) |
| 6C/6D | current pet position (nibble offset in the buffer, 8 bits) |
| 6E/6F | sprite ids (2 frames) coming from TBL_A00 |
| 70 | movement flags (high nibble of the step's 1st byte): bit3 = draws upper half, bit2 = draws lower half, bit1 = mirrors upper, bit0 = mirrors lower |
| 3A/3B | copy of 6C/6D = drawing destination (X = 0x1:{3B}{3A}) — also reused as the clock's destination |
Pose flags M63: bit1 chooses the UPPER half's sprite (0 -> M6E, 1 -> M6F), bit0 chooses the LOWER half's; bit3/bit2 = mirroring inversion (xor) of upper/lower.
```c
void step_pet_animation(void) {
  // --- pose script (page 0xB): each entry = 1 byte {flags(hi), delay(lo)} ---
  if (M[0x5F] == 0) {                       // add mx,0xF produces no carry => it was 0
    p = {M[0x65]:M[0x64]}; {M[0x65]:M[0x64]} = p + 1;
    TBL_PAGE_B[p] -> retd writes {M[0x63]:M[0x62]};   // entries "lbpx byte; retd ptr" rewrite M64/65 (jump/loop)
    M[0x5F] = M[0x62];
  } else M[0x5F]--;
  // --- movement script (page 9): entry = 2 bytes ---
  c = {M[0x67]:M[0x66]};
  if (c == 0) {                              // it was 0 => fetch
    p = {M[0x6B]:M[0x6A]}; {M[0x6B]:M[0x6A]} = p + 2;
    TBL_PAGE_9[p] -> writes M66,M67 (byte0: lo=delay, hi=flags) and M68,M69 (byte1: argument) ; jump entries also rewrite M6A/6B
    M[0x70] = M[0x67]; M[0x67] = 0;
    // (the counter is M66 after loading: the step lasts M66+1 frames; the decrement above does {67:66}-- and only fetches when it was 0)
  } else { {M[0x67]:M[0x66]} = c - 1; }
  // position: executed EVERY frame
  arg = {M[0x69]:M[0x68]};
  pos = (arg & 1) ? ({M[0x6D]:M[0x6C]} + (arg & 0xFE)) : arg;      // relative (delta accumulated per frame, 8 bits mod 256) or absolute
  {M[0x6D]:M[0x6C]} = pos;  {M[0x3B]:M[0x3A]} = pos;
  // drawing
  if (M[0x70] & 8) {                         // upper
    sprite = (M[0x63] & 2) ? M[0x6F] : M[0x6E];
    flip   = (M[0x70]<<2 ^ M[0x63]) & 8;     // = M70.bit1 ^ M63.bit3 in bit3
    label_288(sprite, flip);                 // 0x928: draws at X={3B:3A}, page 1
  }
  M[0x3B] += 8;                              // = +0x80: lower half (seen: ldx 0x3B add 8)
  if (M[0x70] & 4) {                         // lower
    sprite = (M[0x63] & 1) ? M[0x6F] : M[0x6E];
    flip   = ((M[0x70]<<2 ^ M[0x63]) << 1) & 8;   // M70.bit0 ^ M63.bit2
    label_289(sprite, flip);
  }
}
```
Notes/evidence: (1) the movement jump-or-fetch uses `add mx,0xF; adc mx,0xF` on {67:66}: when the value is !=0 there is always a carry (decrement),
when 0 it becomes 0xFF and falls into the fetch (trace: M66/M67 go to F and are soon rewritten by 09BB: `0.190 0497 066 0->F; 0.193 09BB 066 F->0, 067 F->C`).
(2) M3B is incremented by 8 and NOT restored: at the end of the frame {3B:3A} points at the lower half (the next frame recomputes it).
Observed: M70=C (0xC=1100b: upper+lower, no mirroring) in the baby trace. Bits 0/1 of M70 and bits 2/3 of M63 are only inferred from the code (?).
(3) Baby movement entries (0x99B…): `lbpx 0xC0; retd 0x12` = {delay 0, flags C} + absolute position 0x12 (nibbles = column 9);
`lbpx 0xC1; retd 0xFB` = delay 1, relative, delta 0xFA (-6 nibbles = -3 columns/frame); `lbpx 0xCF; lbpx 0x10; retd 0x9B` = stays 16 frames at 0x10 and goes back to 0x99B.
(4) Pose entries: `retd 0x01` (delay 1, flags 0), `lbpx 0x31; retd 0xCA` (flags 3 delay 1 + jumps ptr to 0xCA) at 0xBCA/BCB — a loop of 2 poses.
The data of these tables (0x98B..0x9FF, 0xA00, 0xB00, 0xBC0..0xBFF) belongs to other ranges; the format is above.

Thunks: `jp_table_0x980`(0x482), `jp_table_0xB00`(0x484), `jp_table_0xB00_2`(0x4E3), `jp_table_0x980_2`(0x4E5): `pset 9|B; jpba` — the target's `retd` returns to the thunk's caller.

## 4. `enter_clock_screen_from_pet` — 0x4E7–0x4FD (agg23 `label_155`)
Entry 0 of the menu's jump table (0x700: `pset 4; jp label_155`) — button M on the pet screen with no icon selected. Prepares the clock on the RIGHT page,
scrolls the window to it and enters the clock screen loop (`label_88`, 0x293).
```c
void enter_clock_screen_from_pet(void) {
  clear_nibbles(0x140, 64); clear_nibbles(0x1C0, 64);     // label_245(A=0): XP=1, clears 4*A nibbles (A=0 -> 64)
  {M[0x3B]:M[0x3A]} = 0xC4;                               // clock destination = 0x1C4
  draw_clock();                                           // label_181
  clear_nibbles(0x170, 16);                               // clears the right tip (seconds) of the upper half
  scroll_view_right(limit_hi = 4, step = 4);              // label_305(A=4,B=4): ptr 0,4,..,0x40
  goto clock_screen_loop;                                 // pset 2; jp 0x293 (label_88)
}
```
`label_245` (0x80D, outside the range): `XP=1; do { 4 nibbles = 0 } while(--A)` (A=0 -> 16 iterations).

## 5. `scroll_view_left` — 0x500–0x507 (agg23 `label_156`)
Input: B = step. Shows the buffer scrolling the window to the LEFT from the current ptr to 0 (transition effect to the pet screen).
```c
void scroll_view_left(uint4 B) {
  do {
    copy_video_buf_to_vram();                        // calz 0x56
    lo = M[0x2A] + B;  M[0x2A] = lo & 15;
    hi = M[0x2B] + 0xF + (lo>>4); M[0x2B] = hi & 15;
  } while (hi > 15);                                 // ptr -= (16-B)  (8-bit arithmetic); exits when it "borrows"
}
```
With B=0xC (step 4 nibbles = 2 columns) from 0x40: 17 copies (ptr 0x40,0x3C,…,0x00); B=0xE: step 2. On exit, ptr = 0xFC (or 0xFE) — the
caller must call `clear_page_0x100` before using ptr again. Called at 0x3CE (B=E), 0x511 (B=C), 0x648 (B=C).
Counterpart: `label_305` (0xAF0) = `scroll_view_right(A=limit of ptr's high nibble, B=step)`: ptr=0; repeat {copy; if M2B>=A exit; ptr+=B}.

### 6.2 `pet_screen_loop` — 0x512–0x54C (`label_158`..`label_165`)
```c

label_159: M[0xA0] = 0;                           // remembered cursor := no icon
label_160: B = 0xA; A = (M[0x7C] == 0xF) ? 8 : 1;  // 8 positions (0..7) if hatched; 1 (only 0) if still an egg

             }
```

Jump table 0x700 (cursor → target; icon in the P1's order; names marked (?) are inferred from the code):
0 → 0x4E7 clock (no icon); 1 → label_220 0x710 food (?); 2 → label_297 0xABE light (reads M4B, toggles M78) ; 3 → label_196 0x624 game
(refuses if sleeping/sick: checks M4A/M48); 4 → label_191 0x600 medicine (?); 5 → label_336 0xD7E toilet (?); 6 → label_247 0x814 status
(4 pages, counter M80); 7 → label_301 0xADA discipline (?). Entries 1..7 return to the loop via `jp label_160` (0x623,0x721,0x835,0xAD9,0xAEF,0xD93 ...).
Called by: 0x2B4/0x2BB (from 0x2xx, coming from the clock) and return from menus (`jp label_160`/`label_159`).
Evidence (trace out/sub400d, baby0.sav): each `press L` writes M28/M29=4 (bit2), M57: 9->A (reload) and M75: 0→1→2→3 (pc 02D4); M is dispatch (pc 0666 writes M57=F at the target of cursor 3).
Timeout: M57 is decremented 1x/s by the clock interrupt (pc 0132) and reloaded with M77 on every button; zero ⇒ `menu_poll` returns C=1 (cancel).

`menu_poll` (label_94, 0x2C3, outside the range, but needed): reads events (`copy_0x026_7_to_8_9`: A=M26 state of held buttons; M27 = press
events, cleared on reading; both copied to M28/M29). Returns A=cursor M75, flags: L (M29 bit2): beep, M75=(M75+1)<M76 ? M75+1 : 0 → C=0,Z=0;
M (bit1): beep, C=0,Z=1; R (bit0): beep, C=1,Z=1; no button and M57==0 and M77!=0: C=1,Z=0 (timeout). Any button reloads M57=M77 (if M77!=0).
ISR (0x18B–0x19E): M26 = level, M27 |= new presses, and auto-repeat after 8 ticks with mask M3F.

## 7. Clock-setting screen — 0x553–0x590 (`label_167`..`label_174`)
Entry points: 0x2B7 (A==5: L+R held on the clock screen) and 0x98A (initial start-up loop; see script scripts/boot_set_clock.txt: M on the egg).
```c
void set_clock_screen(void) {              // label_167
  beep_click(); set_icon_highlight(0); clear_page_0x100();
  X = 0x1E0; misc_render(0x0C); misc_render(0x0D);     // 0x1660 "S|" + 0x1668 "ET" = the text "SET" (bottom right corner of the right page)
  M[0x3C] = 0;                  // clock STOPPED (the 1 Hz ISR only counts seconds if M3C != 0; confirmed at 0x133-0x13A)
  M[0x10] = M[0x11] = 0;        // seconds := 00
  M[0x3F] = 6;                  // auto-repeat mask (M and L repeat when held; see ISR 0x19A)
  draw_clock_screen();          // label_175
  while (held_buttons() != 0);  // label_168: waits for everything to be released (A=M26)
  for(;;) {
    draw_clock_screen();        // label_169
    for(;;) {                   // label_170
      poll();                   // copy_0x026_7_to_8_9 (A=held, M29=events)
      if (M29 & 1) { beep; M3F = 0; /* if M15>=2 → 0x97F (never happens: hour<24) */ M3C = 0xF; goto clock_screen_loop; }   // R: confirm; the clock starts running
      if (M29 & 2) { beep; minutes_inc_wrap60(); M2E = 0xF; }    // M: +1 min (label_35 @0xE2: BCD in M12/M13, D=1; M13>=6 => 0; does NOT carry into the hour)
      if (M29 & 4) { beep; hour = {M15&1:M14}; hour = (hour+1 >= 24) ? 0 : hour+1; store; goto redraw; }   // L: +1 h (label_67 @0x1F4)
      if (M2E == 0) continue;   // nothing changed
      break;                    // redraw
    }
  }
}
```
Hour in M14 (low nibble) / M15 (high nibble) in BINARY (0..23, `{15:14}`), BCD minutes M12/M13, BCD seconds M10/M11. M2E = "clock changed, redraw"
(the 1 Hz ISR sets 1; `draw_clock` clears). Evidence: scripts/boot_set_clock.txt (L=+1h, M=+1min, R=confirm) and dump out/sub400e (M2A/2B=0/4, M3A/3B=4/C).

### 7.1 `draw_clock_screen` — 0x591–0x595 (`label_175`)

## 9. `draw_clock` — 0x5A6–0x5E2 (`label_181` + `render_clock_values`)
Draws the time in the buffer starting at X = 0x1:{M3B:M3A} (normally 0x1C4). Called at 0x29A, 0x4F3, 0x593.
```c
void draw_clock(void) {
  X(xp=0); IRQ off (clear_0x07D);
  M[0x2E] = 0;
  m4=M[0x10]; m5=M[0x11]; m6=M[0x12]; m7=M[0x13]; A=M[0x14]; B=M[0x15];    // atomic snapshot (sec, min, hour)
  IRQ on (set_f_0x07D);
  hour24_to_12h(A,B);                           // -> M8 (units), M9 (tens bits0-1 | PM<<3)    (X=8)
  X = 0x100 | {M3B:M3A};                        // XP=1
  misc_render(v = 0xA + ((M9>>3)&1));           // 0x1650 "AM" / 0x1658 "PM" (vertical) – 16 nibbles in the lower half
  clear_16_addrs();                             // 16 more blank nibbles
  X += 0x60 (with 8-bit wrap, xh += 6): goes to the upper half: (0x1C4 → 0x144)
  if (M9 & 3) glyph_big(M9 & 3); else clear_8();       // hour tens (empty if 0)
  blank(2); glyph_big(m8);                             // hour units
  blank(2) ; col(0x22) ; blank(2)                       // ':' (3 columns: 00 22 00)
  glyph_big(m7); blank(2); glyph_big(m6);               // minutes
  blank(4); glyph_small(m5); blank(2); glyph_small(m4);// seconds (small font = index +10)
}
// glyph_big(d)  = render_asset(page 0x15, off = 4*d)          (0x1500+4d, 8 nibbles) -> setup_addr_and_render_clock
// glyph_small(d)= render_asset(page 0x15, off = 4*(d+10))     (0x1528+4d)            -> render_clock_with_b_0
```
Sum of nibbles: 8+2+8+6+8+2+8+4+8+2+8 = 64 (total width 32 columns, starting at 0x144 → the 2 last nibbles... the last 4 nibbles invade 0x180–0x183 (?); the start at 0x144 and the position of the ':' at 0x156–0x15B are
confirmed in the dump out/sub400e/ram.txt: `158: 22`).
In `enter_clock_screen_from_pet` the seconds (0x170–0x17F) are erased afterwards.

### 9.1 `hour24_to_12h` — 0x5E3–0x5EE (`label_184`..`label_186`)
Input B:A = hour 0..23 as a binary byte (A=low nibble, B=high) and X=8. If B<1 or (B==1 and A<8): `{m1:m0} = (B:A) + 0xE6` (0xE6 = `+6` on the low nibble, `+0xE` on the high, with carry) and
`m2=5` → `render_asset` in page 0x15, which falls into the `retd` of the 24-entry table at 0x15E6:
`h=0→0x12, 1..9→0x01..0x09, 10→0x10, 11→0x11, 12→0x92, 13..21→0x81..0x89 (pm: 0x80|h-12), 22→0x90, 23→0x91`.
Output: M[8] = low nibble (BCD units), M[9] = high nibble: bits0-1 tens (0/1), bit3 = PM. Invalid hour (>=24) → `retd 0` (M8=M9=0).

### 9.2 `render_clock_with_b_0` 0x5EF / `setup_addr_and_render_clock` 0x5F3 / `render_clock_page` 0x5FB
```c
render_clock_with_b_0(A):  B=0; (B:A) = A + 10;  goto skip;     // small font
setup_addr_and_render_clock(A): B=0;
skip: (B:A) <<= 2;  M0=A; M1=B;  A=5;
render_clock_page: M2=A; pset 0; jp render_asset;               // render_asset (0x000): page (M2&7)*4 in table 0x1000; M1:M0 = offset. M2=5 => 0x15xx
```
Called by: 0x5D0-0x5E2 (draw_clock) and 0x2AA (render_clock_with_b_0, in the clock loop).
