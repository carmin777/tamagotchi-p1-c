Pre-release: **not yet tested on real Windows or Android devices** (it builds on CI, and the game logic is the one validated against the emulator).

**The ROM is not included** — you need your own dump of the P1 ROM (`tama.b`, 12288 bytes, md5 `3fce172403c27274e59723bbb9f6d8e9`).

- **Windows** (`tamagotchi-p1-windows.zip`): unzip, open `tamagotchi-p1.exe` and drag `tama.b` onto the window (first run only). Keys: arrows or A S D, F = 10x.
- **Android** (`tamagotchi-p1-android.apk`): install it (allow "unknown sources"), open the app and pick `tama.b` in the file picker. Controls: three on-screen buttons.

Debug APK, signed with the debug key; meant for sideloading.
